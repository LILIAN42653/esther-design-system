# 质量检查清单

> 做完设计后逐条对照。P0必须全过，否则打回修改。

---

## P0（必须全过）

任何一条不过就要改：

- [ ] 品牌四色可见面积约为酪乳黄50% / 旧勃艮第棕25% / 柔雾蓝15% / 奶油米黄10%
- [ ] 四色都形成可见板块或承托面，不是只出现在按钮、圆点和小装饰里
- [ ] 没有同色元素融入同色背景；色块、节点和装饰条都有描边、`#FFF8DE` 小型过渡面或异色内缩区
- [ ] 第四辅助色 `#FFF8DE` 用于过渡描边、小型状态节点、预览画布或局部承托，没有取代三主色成为页面、section 或大卡片主体背景
- [ ] 多级流程没有使用三个彩色大圆和渐变连接线；优先使用小胶囊节点与单色细连接线
- [ ] 个人品牌页面至少出现一次 `assets/avatar.png` 或栗栗安签名档，且头像成功加载
- [ ] 没有旧头像、内嵌 base64 身份图、`placeholder.jpg` 或外部链接头像
- [ ] 没有使用禁忌清单里的任何元素（科技蓝/蓝紫渐变/glassmorphism/neon/黑客终端感/bounce动画/居中病）
- [ ] 页面与 section 主背景使用酪乳黄 `#FFF1B5` 或柔雾蓝 `#C1DBE8`；暖白 `#FFFEFA` 只用于卡片内部且可见面积不超过 20%
- [ ] 没有继续使用其他暖米灰，也没有把旧中性色 `#FFF9ED` / `#F5EBD8` / `#EDE4D5` 用作大面积背景
- [ ] 字体用了推荐字体池里的（Fraunces/Noto Serif SC/Caveat等）
- [ ] 标题衬线+正文无衬线混搭
- [ ] 有响应式（至少900px断点）
- [ ] 截图发Twitter不会被说"又是AI做的"
- [ ] 每个section布局形式不同
- [ ] clamp()做fluid sizing
- [ ] 没有使用任何HTML默认样式（默认blockquote、默认border-left引用、无样式ul/ol、默认table）——所有组件必须从components.md选用

---

## P1（应过）

尽量满足，提升品质：

- [ ] 至少一个section有视觉惊喜（出血/3D/全宽色块/装饰突破）
- [ ] 字号对比足够极端（大的>3rem，小的<0.85rem）
- [ ] 有Scroll Reveal动效 + stagger延迟
- [ ] 使用了大装饰数字或大透明英文做背景
- [ ] 有品牌色条（border-left）或高亮标记
- [ ] ::selection用强调色高亮

---

## P2（加分）

锦上添花：

- [ ] 图片溢出容器边界
- [ ] 有全宽深色面板打破节奏
- [ ] 装饰元素（虚线圆/渐变光晕/条纹肌理）使用克制
- [ ] prefers-reduced-motion尊重
